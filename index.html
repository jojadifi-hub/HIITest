💾 Copia de Seguridad Local (JSON) y Explicación
¿Qué es un archivo JSON y para qué sirve?
JSON (JavaScript Object Notation) es un formato de texto estructurado ultra ligero. HIITest lo utiliza para exportar e importar tus temas, preguntas y notas personales en un solo archivo. Te sirve para guardar copias de seguridad en tu equipo o compartir exámenes directamente con compañeros.
